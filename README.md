# Responsabilidad-nica-
//Con este la idea es que cada clase debe de tener una sola razón para cambiar, debe encargarse de una única tarea o responsabilidad dentro del programa.La clase Libro su unica responsabilidad es manejar los datos propios del libro, como guardar y todo lo demas con sus getters y setters, esta clase no se mete con el almacenamiento ni con la persistencia. La clase Guardar su unica funcion es encargarse del proceso de guardar el libro mediante el metodo GuardarLibro. En el main se crea el objeto Libro para definir sus datos y luego uso Guardar para procesarlo.
